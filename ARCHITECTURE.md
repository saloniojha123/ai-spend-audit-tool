
# System Architecture

## Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript (for type-safety and scalability)
- **Styling**: Tailwind CSS
- **Icons**: Lucide-React
- **Deployment**: Vercel (CI/CD)

## Data Flow
1. User inputs monthly SaaS spend.
2. Logic Engine calculates 30% arbitrage savings.
3. State is persisted via `localStorage` for session continuity.
4. Lead Capture Modal converts high-intent users into Credex prospects.
